USP Secure Entry Server ® 5.12.0.3

SES 5.12.0.3 consists of the following components:

  • SES Web GUI 5.12.0.3
  • HTTP Secure Proxy (HSP) 4.23.0.0
  • Secure Login Service (SLS) 5.15.0.7
  • Identity Manager (IDM) 2.1.0.3
  • Shared Appliance Base (SAB) 1.16.12

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R640
  • Dell PowerEdge R630

Secure Login Service (SLS)

Bugfixes

  • The Log4j 1.2.17 library used by the SLS has been patched and a few classes were removed that were responsible for some known vulnerabilities. However, none of these vulnerabilities affected SLS instances in any SES setups, as they relied on Log4j functionality not used by the SLS. Still, just to address any lingering doubts, these classes were removed. The vulnerabilities addressed by the patch are:
    • CVE–2021–4104
    • CVE–2020–9488
    • CVE–2019–17571
