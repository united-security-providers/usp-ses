USP Secure Entry Server ® 5.18.0.0

SES 5.18.0.0 consists of the following components:

  • SES Web GUI 5.18.0.0
  • HTTP Secure Proxy (HSP) 4.27.0.4
  • Secure Login Service (SLS) 5.20.0.5
  • Identity Manager (IDM) 2.3.0.1
  • Shared Appliance Base (SAB) 1.17.6

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R660
  • Dell PowerEdge R650
  • Dell PowerEdge R640

Secure Login Service (SLS)

Various Improvements and Fixes

  • A build issue with the SLS scripting guide documentation has been fixed which resulted in some scripting prefixes like “oidc_rp” not having been included previously.
  • Fixed minor issue with exception being logged during session clean-up under certain circumstances involving the hard final timeout and concurrent request processing.
  • Fixed issue with Google Authenticator QR code not being rendered due to default Content Security Policy.
