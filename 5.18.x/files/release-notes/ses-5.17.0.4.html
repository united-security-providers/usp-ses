USP Secure Entry Server ® 5.17.0.4

SES 5.17.0.4 consists of the following components:

  • SES Web GUI 5.17.0.4
  • HTTP Secure Proxy (HSP) 4.27.0.2
  • Secure Login Service (SLS) 5.20.0.3
  • Identity Manager (IDM) 2.3.0.1
  • Shared Appliance Base (SAB) 1.17.6

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R660
  • Dell PowerEdge R650
  • Dell PowerEdge R640
  • Dell PowerEdge R630
