USP Secure Entry Server ® 5.8.0.8

SES 5.8.0.8 consists of the following components:

  • SES Web GUI 5.8.0.8
  • HTTP Secure Proxy (HSP) 4.18.0.4

  • Identity Manager (IDM) 1.4.0.7
  • FUSE ICAP Server 1.3.4
  • Shared Appliance Base (SAB) 1.16.2

  • Dell PowerEdge R630
