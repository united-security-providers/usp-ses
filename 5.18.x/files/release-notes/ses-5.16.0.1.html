USP Secure Entry Server ® 5.16.0.1

SES 5.16.0.1 consists of the following components:

  • SES Web GUI 5.16.0.1
  • HTTP Secure Proxy (HSP) 4.26.0.2
  • Secure Login Service (SLS) 5.19.0.1
  • Identity Manager (IDM) 2.3.0.1
  • Shared Appliance Base (SAB) 1.17.2

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R650
  • Dell PowerEdge R640
  • Dell PowerEdge R630
