USP Secure Entry Server ® 5.9.0.3

SES 5.9.0.3 consists of the following components:

  • SES Web GUI 5.9.0.3
  • HTTP Secure Proxy (HSP) 4.20.0.3

  • Identity Manager (IDM) 1.5.0.1
  • Shared Appliance Base (SAB) 1.16.5

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R640
  • Dell PowerEdge R630
