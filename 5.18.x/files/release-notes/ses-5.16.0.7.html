USP Secure Entry Server ® 5.16.0.7

SES 5.16.0.7 consists of the following components:

  • SES Web GUI 5.16.0.6
  • HTTP Secure Proxy (HSP) 4.26.0.5
  • Secure Login Service (SLS) 5.19.0.4
  • Identity Manager (IDM) Core 2.3.0.1
  • Identity Manager (IDM) Web GUI 2.3.0.1
  • Shared Appliance Base (SAB) 1.17.5

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R650
  • Dell PowerEdge R640
  • Dell PowerEdge R630

Secure Login Service (SLS)

Various Improvements and Fixes

  • The OIDC OP no longer redirects to the redirect_uri in case of an unknown or missing client_id in the authentication request, in order to prevent attacks that would redirect via the trusted OP domain to an “evil” domain.
