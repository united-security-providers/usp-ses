USP Secure Entry Server ® 5.10.0.7

SES 5.10.0.7 consists of the following components:

  • SES Web GUI 5.10.0.6
  • HTTP Secure Proxy (HSP) 4.21.0.5
  • Secure Login Service (SLS) 5.13.0.4
  • Identity Manager (IDM) 1.6.0.2
  • Shared Appliance Base (SAB) 1.16.8

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R640
  • Dell PowerEdge R630

Secure Login Service (SLS)

Various Improvements and Fixes

  • Fixed a bug in the slowdown mechanism which could lead to a model state being skipped by using POST requests during the slowdown waiting time. This bug was introduced by another fix (of a potential infinite loop during slowdown) which was done in SLS 5.13.0.0 (SES 5.10.0.0).
