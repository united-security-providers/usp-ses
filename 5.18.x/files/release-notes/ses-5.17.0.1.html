Secure Login Service (SLS)

Various Improvements and Fixes

  • Fixed bug in CSP feature which lead to some HTML elements generated by the SLS tag library receiving the same “id” attribute value in multiple occurrences of the same tag, potentially leading to problems with JavaScript or styles using these ids.
  • Internally a newer Nimbus JOSE library is used for JWT handling (8.x => 10.x) to fix security vulnerabilities.
    • The JWKS returned by the OIDC Operator script functions now contains exp and nbf claims.
    • Integrations that directly use the Nimbus JOSE library via Groovy to access parsed JWT-related objects should replace references to net.minidev.json.JSONArray by List or just use def, and note that the auth_time claim in JWTs is now parsed to a Date, like iat and exp claims already before, no longer to a long integer.
  • Fixed rare NullPointerException during session clean-up, caused by racing condition between regular session clean-up thread and final timeout clean-up.
