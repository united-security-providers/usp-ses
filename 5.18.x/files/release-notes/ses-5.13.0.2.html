USP Secure Entry Server ® 5.13.0.2

SES 5.13.0.2 consists of the following components:

  • SES Web GUI 5.13.0.2
  • HTTP Secure Proxy (HSP) 4.23.0.5
  • Secure Login Service (SLS) 5.16.0.3
  • Identity Manager (IDM) 2.2.0.1
  • Shared Appliance Base (SAB) 1.17.0

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R640
  • Dell PowerEdge R630
