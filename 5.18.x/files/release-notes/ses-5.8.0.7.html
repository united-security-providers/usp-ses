USP Secure Entry Server ® 5.8.0.7

SES 5.8.0.7 consists of the following components:

  • SES Web GUI 5.8.0.6
  • HTTP Secure Proxy (HSP) 4.18.0.4
  • Secure Login Service (SLS) 5.10.0.2
  • Identity Manager (IDM) 1.4.0.6
  • FUSE ICAP Server 1.3.4
  • Shared Appliance Base (SAB) 1.16.2

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R640
  • Dell PowerEdge R630
