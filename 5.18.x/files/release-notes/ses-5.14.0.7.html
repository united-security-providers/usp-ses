USP Secure Entry Server ® 5.14.0.7

SES 5.14.0.7 consists of the following components:

  • SES Web GUI 5.14.0.5
  • HTTP Secure Proxy (HSP) 4.24.0.7
  • Secure Login Service (SLS) 5.17.0.1
  • Identity Manager (IDM) 2.3.0.0
  • Shared Appliance Base (SAB) 1.17.0

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R650
  • Dell PowerEdge R640
  • Dell PowerEdge R630
