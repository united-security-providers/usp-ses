USP Secure Entry Server ® 5.7.0.0

SES 5.7.0.0 consists of the following components:

  • SES Web GUI 5.7.0.0
  • HTTP Secure Proxy (HSP) 4.17.0.4
  • Secure Login Service (SLS) 5.8.0.0
  • Identity Manager (IDM) 1.2.0.0
  • FUSE ICAP Server 1.3.4
  • Shared Appliance Base (SAB) 1.15.7

Platform Compatibility

This release is compatible with the following hardware platforms:

  • Dell PowerEdge R640
  • Dell PowerEdge R630
